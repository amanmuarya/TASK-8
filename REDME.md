
# Mobile Laundry Service Landing Page

A responsive, mobile-first landing page built for a laundry and dry cleaning service. This project featues a clean UI with a smooth, slide-in side navigation bar (hamburger menu).

## 🚀 Features

* **Mobile-First Design: Optimized specifically for smartphone screens.
* **Interactive Sidebar: A dark-themed side navigation menu that smoothly slides in from the right.
* **Background Overlay: Dimmed background effect when the menu
 is open to focus user attention and allow easy closing.
* **Clean UI: Modern typography, soft colors, and a
 highlighted call-to-action matcing the brand identity.
* **No External Libraries:Built compleely using pure HTML  CSS, and a few lines of Vanilla JavaScript.

##  Technologies Used

* **HTML : For the page structure and semantic layout.
* **CSS : For styling, spacing, and the slide-in/slide-out animations.
* **JavaScript:** Simple inline functions to toggle the sidebar's visibility.
